================================================================
 Autovisor 面板  使用说明
================================================================

一、这是什么
------------------------------------------------
这是一个给 Autovisor（智慧树课程自动学习工具）配的图形界面外壳。
上游内核由 CXRunfree/Autovisor 提供，本面板只负责配置、启动与状态展示，
不修改上游程序的任何文件。

主要能力
  · 图形化填写全部配置，不用再手工编辑 config.ini
  · 密码用 Windows DPAPI 加密保存，配置文件里不出现明文
  · 一键开始 / 停止，按进程树结束浏览器
  · 实时显示当前课时、平台进度、已完成节数、日志
  · 检测到游戏（按 GPU 3D 占用）自动暂停刷课，游戏结束后恢复
  · 疑似卡死时用 Windows 系统通知在右下角提醒，点击通知可唤起面板
  · 两栏之间可拖拽分隔条，比例自动记住


二、运行环境
------------------------------------------------
  · Windows 10 / 11（64 位）
  · 已安装 Edge 或 Chrome（程序不自带浏览器）
  · 需要联网（首次运行要下载 numpy / opencv）
  · 无需安装 Python、.NET SDK 或任何运行时


三、快速开始
------------------------------------------------
  1) 解压整个压缩包到任意可写目录
     不要放在 C:\Program Files 这类没有写权限的位置

  2) 双击 AutovisorPanel.exe

  3) 在「配置」区填写：
     账号    —— 手机号或账号
     密码    —— 填写后点右侧小眼睛可临时查看，默认以星号隐藏
     浏览器  —— Edge 或 Chrome，路径一般留空
     课程链接 —— 一行一个，必须是课程播放页的地址（能看到视频目录那一页）

  4) 点「开始刷课」
     首次运行会自动下载 numpy 与 opencv 到 runtime\packages，需要几分钟

  5) 想停止就点「停止」，或直接关闭面板（会提示确认）


四、界面说明
------------------------------------------------
配置区
  账号 / 密码      留空则打开浏览器后手动登录（更安全）
  浏览器 / 路径    路径留空使用系统默认安装位置
  每门课上限       单位分钟，0 表示不限制，学到完为止
  倍速             1.0 ~ 1.8，平台允许的最高倍速
  静音播放         自动把播放器音量设为 0
  自动过滑块       登录时自动完成易盾滑块验证
  隐藏窗口         把浏览器移出屏幕，遇到验证码会自动显示
  显示赞赏码       是否展示上游作者的赞赏二维码
  课程链接         每行一个，必须以 https:// 开头
  游戏时自动暂停   检测到游戏就暂停刷课，勾选状态会被记住

状态区
  右上角徽标       未运行 / 刷课中 / 待处理 / 游戏暂停
  当前课时         第 N/M 节 及课时名称
  平台进度         平台记录的百分比，配进度条
  已完成节数       本轮已完成的课时数
  日志静默         距日志最后一次写入的时间，超过 10 分钟变橙色
  最近日志         实时滚动，最多保留 40 行
  底部提示         游戏检测的当前状态


五、常见问题
------------------------------------------------
Q: 杀毒软件报警或文件被删？
A: 上游是 PyInstaller 打包且做过 UPX 压缩，容易触发启发式误报。
   把整个目录加入信任区后重新解压即可。

Q: 提示「未找到 Autovisor.exe」？
A: 确认 runtime 目录完整，且没有被移动过。目录结构见第七节。

Q: 首次启动卡在下载依赖？
A: 正在下载 numpy / opencv（约 50 MB）。网络不好会较慢，
   也可以手动修改 runtime\data\mirrors.json 更换镜像源。

Q: 一直停在「正在等待登录完成」？
A: 账号密码留空时需要你在弹出的浏览器里手动登录；
   或者检查登录页是否改版，尝试更新上游版本。

Q: 弹出安全验证 / 课中弹题？
A: 面板徽标会变红并闪烁任务栏。
   安全验证必须人工完成；课中弹题上游会自动选第一个选项并提交。

Q: 怎么知道它卡住了？
A: 日志超过 10 分钟没有新内容时，面板会在屏幕右下角弹出系统通知
   「刷课可能卡住了」，同时任务栏图标闪烁、右上角徽标变红。
   通知只弹一次；若持续卡死，每 15 分钟补一次提醒。
   点击该通知可把面板窗口调到前台。全屏游戏期间不弹通知。

Q: 打游戏时会被弹窗打断吗？
A: 已内置检测：任一进程 GPU 3D 占用 ≥25% 且持续 15 秒即判定为游戏，
   立即停止刷课；连续 60 秒空闲后自动恢复。
   事件记录在 logs\panel.log。

Q: 中途关掉面板，刷课会停吗？
A: 会。面板退出时会询问是否停止刷课，选择「是」则一并结束。
   如果只想关界面但继续刷课，请选「否」——注意普通关闭会停止刷课。


六、隐私与安全
------------------------------------------------
  · 密码：用 Windows DPAPI（当前用户作用域）加密后存于 data\cred.bin，
    换电脑或换 Windows 账户都无法解密；config.ini 中的 password 恒为空。
  · 运行期：生成临时配置传给上游，停止或退出时删除，下次启动清理两天前的残留。
  · Cookie：登录后由上游写入 runtime\data\cookies.json，
    它等价于你的登录状态，请勿分享，不用时可直接删除。
  · 日志：runtime\logs 记录了课程与课时名称，属于个人学习记录。
  · 本软件不会向作者或任何第三方服务器上传数据；
    仅有三个网络去向：智慧树站点、GitHub（检查上游更新）、PyPI 镜像（下载依赖）。
  · 打包时已剔除 cookies.json、cred.bin、logs、packages，
    因此分发包里不含任何账号信息。


七、目录结构
------------------------------------------------
  AutovisorPanel.exe     面板本体（约 44 KB）
  config.ini            配置文件，账号密码可留空
  使用说明.txt           本文件
  runtime\              上游发行包，请勿单独移动
    Autovisor.exe         上游主程序
    internal\             Python 运行时与 Playwright
    resources\            反爬脚本与图片资源
    data\                 mirrors.json、cookies.json（运行后生成）
    logs\                 运行日志（运行后生成）
    packages\             自动下载的 numpy / opencv（运行后生成）
